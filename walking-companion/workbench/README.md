# UNION expression workbench

Reuses the AirBoat expression workbench from the local AirBoat_Face_Expression project. Original node relationships, six asset versions, EAF/AFM players, replacement drafts, export, and side-by-side comparison are retained. `union-theme.css` adapts the interface to UNION; `union-bridge.js` handles the containing page and compact views. Actual animation colors remain unchanged.

Animation datasets include the original source and MIT license notice, available from 制作规范 → 原版素材授权与来源. Replacement drafts remain in this browser's local storage and can be exported as JSON. This workbench previews assets and does not connect to physical hardware.

The original build-budget report is not part of this website bundle; the available budget summary remains inside 制作规范.

Upstream synchronized to `9a21009852a16bdc342827b91a7d7102f4956659` (main), including Contour / 微动作 and Square Pop / 方圆怪趣. `upstream-version.json` records exact upstream and adapted file hashes.
